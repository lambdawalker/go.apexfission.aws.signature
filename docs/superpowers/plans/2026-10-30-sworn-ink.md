# Sworn Ink Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans or focused parallel workers for independent Android and infrastructure tasks. Use checkbox steps for tracking.

**Goal:** Deliver interoperable biometric signing and strict hardware verification with deployable AWS infrastructure.
**Architecture:** Android signs server statements. Go validates attestation and ownership, consumes DynamoDB challenges and saves sealed S3 evidence. Pulumi owns resources.
**Tech Stack:** Kotlin Android Keystore/BiometricPrompt; Go; AWS SDK v2; Pulumi Go.
**Spec:** ../specs/2026-10-30-sworn-ink-design.md

## Global Constraints
External JWT/email authentication. No software fallback. Five-minute single-use challenge. P-256/SHA256 DER signatures. No deployment/publication. Authoritative protocol belongs to Go repository.

## Review Focus
- Missing, forged or stale attestation and revocation evidence must fail closed.
- Capability ordering must not permit downgrade or software keys.
- Account crossovers and concurrent/replayed challenges must fail.
- S3 failures must not become successful receipts; exact retries must recover.
- Android cancellation/enrollment changes must not bypass authentication.
